# Installer VELORA AUTOPILOT depuis un iPhone

## Ce qui est déjà fait

Le programme et son workflow GitHub Actions sont écrits et testés : recherche de thèmes, scénario sourcé, six scènes originales en motion design, narration, vrai MP4 vertical, contrôle de durée, suivi de la boucle, reprise et budget nul par défaut.

## La seule étape de compte indispensable

Crée dans ton compte GitHub un **nouveau dépôt public et vide** nommé `velora-autopilot`. N'ajoute pas ce logiciel au dépôt de ton projet immobilier ou à un autre logiciel existant. Un dépôt public permet les runners GitHub standard gratuits, mais son code et ses fichiers de suivi seront visibles par tous. **Ne rends jamais publiques tes clés API, mots de passe, accès YouTube ou fichiers privés.**

Envoie ensuite dans ChatGPT le lien de ce dépôt, dans la conversation où GitHub est connecté, et demande de reprendre l'installation. L'assistant pourra alors essayer d'ajouter tous les fichiers par le connecteur GitHub, sans que tu doives les saisir un par un sur ton téléphone. Le ZIP sert de sauvegarde autonome du programme.

Une fois l'installation GitHub réalisée, active « Actions » et lance le workflow VELORA Autopilot une fois manuellement. La planification quotidienne sera ensuite gérée par GitHub, sans ton iPhone allumé.

## Quand une vidéo est prête

GitHub → ton dépôt → Actions → dernier run → Artifacts → `deesezrxh-production-...` → récupérer le MP4. Elle reste **non publiée** jusqu'à validation et autorisation Google/YouTube.

## Pour de vraies scènes IA génératives

Le dossier contient un adaptateur optionnel Hugging Face ZeroGPU. Il ne fonctionne qu'avec un Space public disposant d'une API réelle, ton token HF personnel, les bons noms de champs et des minutes GPU disponibles. Il refuse les GPU payants. Le rendu par défaut, qui fonctionne sans clé, est du motion design; ce n'est pas une imitation de Seedance.
